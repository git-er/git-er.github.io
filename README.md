# RobW Analytics Portfolio

This repository contains the Quarto source and the rendered static site for the portfolio.

See [PROJECT_SUMMARY.md](PROJECT_SUMMARY.md) for the audience, positioning, current implementation, content status, and future plans.

## Local workflow

1. Open `web_demo.Rproj` in RStudio.
2. Edit the `.qmd` source pages and preview them with Quarto.
3. Render the full site in RStudio before publishing.
4. Review the generated `docs/` output and Git changes before committing or pushing.

The site is hosted on GitHub Pages. The documented publishing setup uses `main` and `docs/`. Do not add client-confidential data, credentials, or personal documents that are not intended for public access.
